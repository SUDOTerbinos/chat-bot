# chat-bot
chat bot that understand 100 word 


#How It Works

Word-Response Dictionary: The chatbot has a predefined dictionary of 100 words and their corresponding responses.

User Interaction: The user types a message, and the chatbot scans the message for any recognized words.

Dynamic Response: If a word matches, the chatbot responds with the appropriate reply. If no match is found, it says, "Sorry, I don't understand that yet."

Exit Option: The user can type "exit" to end the chat.

#Features

Simple and expandable: You can add more word-response pairs to the dictionary.

User-friendly: The chatbot responds dynamically based on keywords.

Fun for beginners: It helps you practice Python basics and logic.
